# Where is the treasure?

So, This is a RPG game made on godot made for Third Space YSWS. Well, this is an complete project.

This is a type of advanture game. So, the player needs to find the hidden clues in the world to proceed to another world.
The clues are the treasure.

## How to Play

WASD — Move

Space — Jump

## Objective

Player have to find all clues(treasure) and kill the boss at the end.

## Installation
Clone the repository:

git clone https://github.com/gunjit-gyawali/Where-s_the_treasure
import game to godot



## Built With

1. Godot
2. GD script
